# SantiCam

Pixel 9a 向け無音カメラの検証・開発リポジトリ。現行のインストール済みアプリの表示名は **しずかカメラ (ShizukaCamera)**、アプリIDは `jp.dharmainsight.shizukacamera`。

## 現在地（2026-11-02）

- アプリから直接起動して撮影可能（ユーザー実機で確認）。
- Pixel 9a / Android 17で、電源ボタン2回押しによるアプリ切替は未解決。
- Pixelカメラを有効にすると2回押しで純正カメラが起動。無効にすると、起動せず画面が消える。
- 1.1.0 APKには通常・ロック画面用カメラ起動Intentの宣言が存在する。ただし、Pixel側の固定起動先か、Activity実装・受け取り処理など、原因は未確定。

## 重要な注意

- **このリポジトリには現時点でオリジナルのKotlin/Java開発ソースがない**。APK静的解析の結果だけで「ビルド可能なソース」とは表記しない。
- 既存APKを同じアプリとして上書き更新するには同一署名鍵が必要。APKから秘密鍵は復元できない。
- 実機のADBでカメラIntentの解決先とPixelの起動設定を調べてから修正する。

診断手順とAPKの検査結果は `docs/` に記録予定。
